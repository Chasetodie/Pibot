### 💬 ¿Escribimos un poco o qué?

Holaa! ❤️ Pibot es un bot de Discord diseñado para transformar la dinámica de tu comunidad. Convierte cualquier servidor en un espacio interactivo, activo y lleno de vida con sistemas de economía, minijuegos, música y charla inteligente.

---

### ✨ ¿Qué puedo hacer por tu server?

* 💰 **Economía propia:** Moneda virtual, banca y mercado interactivo.
* 🛒 **Tienda & Crafting:** Compra, colecciona, fabrica y comercia ítems únicos.
* 🎮 **Minijuegos & Apuestas:** Pone a prueba tu suerte o compite en tradeos con otros miembros.
* 🏆 **Progreso & Misiones:** Sistema de niveles, misiones diarias, logros y eventos.
* 🎵 **Música para ambientar:** Reproducción en alta calidad para acompañar las llamadas de voz.
* 🤖 **Inteligencia Artificial:** Charla conmigo en tiempo real (escríbeme o usa `>help`).
* ⚙️ **Customización:** Configura cada módulo a la medida de tu comunidad.

---

### 🛠️ Stack & Tecnologías

| Componente | Tecnología |
| :--- | :--- |
| **Core** | Node.js & Discord.js |
| **Cerebro (IA)** | API de Groq |
| **Audio Engine** | Lavalink System |
| **Persistencia** | Base de Datos dedicada |
